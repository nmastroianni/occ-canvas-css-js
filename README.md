# Ocean County College - Custom CSS & JavaScript

The files in this repository are uploaded to the Canvas LMS theme editor. To
eliminate the potential for style conflicts, the styles are scoped so that they
will only be applied when the elements are contained within an element with the
correct scope class.

```
<div class="uk-scope">
  <!-- ELEMENTS WITHIN WILL USE THE CUSTOM STYLES -->
</div>
```

## Branches

There are three branches in this repository:

1. main (the live code currently in use)
2. testing (the code that has made it out of beta)
3. beta (new code)
